---
title: 图片分层切换
---

在文章或自定义 Markdown 页面中使用 `layers` 容器，可以用按钮切换同一对象的不同图层：

```markdown
:::layers
![Layer 1: front](/images/layer-1.webp)

![Layer 2: inner 1](/images/layer-2.webp)

![Layer 3: inner 2](/images/layer-3.webp)

![Layer 4: back](/images/layer-4.webp)
:::
```

将示例地址替换为上传后的图片地址；每张图片单独一行，图片之间可以留空行，也可以连续书写。图片说明（`![]` 中的文字）就是按钮名称。至少两张图片才会显示切换按钮，可在同一篇文章中放置多组。共用图注可以放在最后一张图片之后，空一行再写说明文字，切换时会一直显示。

建议各层导出相同的画布尺寸、视角和缩放比例，确保切换时主体对齐。图片使用 4:3 展示区域，完整显示而不裁剪。支持键盘 Tab 聚焦、Enter 或空格切换，并沿用文章图片的点击放大功能。没有 JavaScript 时，所有图片按顺序显示。

此功能用于博客前台，管理后台编辑器暂不提供交互预览。修改后需重新构建、部署 website；已有线上实例不会自动更新。

如果前台出现标题为 `layers` 的普通容器、没有切换按钮，请检查是否已部署包含本功能的构建，并刷新页面。旧版渲染器会把 `layers` 当作普通提示容器；仅修改文章内容或拉取不包含本功能的旧镜像无法启用切换。若使用页面/CDN 缓存，部署后还需要刷新相应缓存。
