ZweiBlog 支持数据的导入和导出。点击后台 `站点管理/系统设置/备份恢复`，点击按钮即可导入导出全部站点信息（除了自定义页面和流水线部分）。

::: warning 恢复前先停止写入

后台 JSON 恢复会预检评论关系、文章 ID 和迁移删除墓碑，并用跨实例 MongoDB 维护锁阻止恢复期间的评论写入。评论集合必须为空，或现有评论 ID 必须全部包含在本次备份中；系统拒绝把备份静默合并到含额外评论的目标库，以免留下旧回复或突破线程上限。MongoDB 单机部署仍无法把所有站点集合放进一个全局事务，因此请在维护窗口中恢复到已做快照的目标库，期间不要发布文章或修改设置；任一环节失败时先回滚目标库快照，再排查备份内容后重试。

后台 JSON 导入和导出共用 `ZWEI_BLOG_BACKUP_MAX_BYTES`，默认 256 MiB。导出内容超过该值时会在下载前明确拒绝，因此不会生成同配置无法导回的文件。需要调高时，源站与恢复目标要设置相同值并重启，最高 512 MiB；更大的站点应使用 `mongodump`、文件系统快照或云数据库快照，避免把整个站点 JSON 同时装入应用内存。

:::

需要注意的是，导入导出并不会实际导出图床中的图片本身，而是导入导出其图片记录以便检索。本地图床时可参考下面的导出全部图片进行导出备份。

![导入/导出](https://www.mereith.com/static/img/917addce2307bc0e470883de035472f5.clipboard-2022-09-01.png)

## 全部数据导出

现在一键脚本可以导出全部数据，包括自定义页面、流水线、图床图片等，具体请参考 [备份与迁移](../guide/backup.md)。

## 导出全部图片

ZweiBlog 支持导出全部 `本地图床图片` 为一个压缩包，你可以在后台中的图片设置中点击按钮来导出全部本地图床图片！（OSS 图床暂不支持全部导出，因为已经在 OSS 中了，完全可以通过 OSS 控制台批量导出，而且备份意义不大）

![导出全部图片](https://www.mereith.com/static/img/dd5f0f0a1ff61a1a5d22c09fcaa8178c.clipboard-2022-09-01.png)
